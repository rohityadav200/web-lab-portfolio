## Lab 7 – Company Employee Management System

### Aim
To develop a company employee management system using PHP and MySQL with user registration, login authentication, sessions, and role-based access control.

### Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

### Features
- Employee registration
- Admin registration
- Secure password hashing
- User login authentication
- PHP session management
- Role-based access control
- Employee dashboard
- Admin dashboard
- Employee can view admin details
- Admin can view employee details
- Logout functionality
- MySQL database integration
