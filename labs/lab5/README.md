# Lab 5 – Employee Registration & Database Management System

## 📌 Objective

To design an employee registration form and store employee details in a MySQL database using PHP.

## 🛠️ Technologies Used

- HTML5
- CSS3
- PHP
- MySQL
- MySQL Workbench
- Visual Studio Code

## ✨ Features

- Employee registration form
- Employee ID
- Full Name
- Email
- Phone Number
- Gender
- Date of Birth
- Department
- Designation
- Salary
- Address
- PHP form processing
- MySQL database storage
- Employee records display
- Responsive employee table

## 🗄️ Database

Database name:

`employee_db`

Table name:

`employees`

The employee details are stored in the MySQL database after submitting the registration form.
