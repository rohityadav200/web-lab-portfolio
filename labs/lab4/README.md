# 🤖 Lab 4 - AI Scientific Calculator

## 📚 Course
**Internet & Web Technologies Lab**

---

## 📌 Objective

To develop a responsive **AI Scientific Calculator** using **HTML, CSS, and JavaScript**. The calculator performs basic and scientific calculations and includes a smart AI assistant capable of answering common mathematics-related questions.

---

## 🚀 Features

### 🧮 Scientific Calculator

- Basic Arithmetic Operations (+, −, ×, ÷)
- Decimal Calculation
- Percentage (%)
- Square Root (√)
- Square (x²)
- Power (xʸ)
- Reciprocal (1/x)
- Absolute Value (|x|)
- Sign Change (±)
- Factorial (!)
- Parentheses Support
- π (Pi)
- Euler's Number (e)
- Trigonometric Functions
  - sin()
  - cos()
  - tan()
- Logarithmic Functions
  - log()
  - ln()
- Previous Answer (Ans)

---

### 🤖 AI Assistant

The built-in AI Assistant can answer common mathematics questions such as:

- What is Factorial?
- Percentage Formula
- Square Root
- Logarithm
- Trigonometric Functions
- Pythagoras Theorem
- Quadratic Formula
- Derivatives
- Integrals

---

### 📝 Additional Features

- Calculation History
- History stored using Local Storage
- Clear History Button
- Responsive Design
- Glassmorphism User Interface
- Modern Dark Theme
