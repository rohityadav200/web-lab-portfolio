# Lab 6 – Department Website with Login and Registration

## Aim

To create a dynamic department webpage with Home, Login, Registration and About Us pages using HTML, CSS, JavaScript, PHP and MySQL.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- MySQL Workbench
- Visual Studio Code

## Features

- Department Home page
- About Us page
- Student Registration
- JavaScript form validation
- MySQL database storage
- Student Login
- Password verification
- PHP session authentication
- Student Dashboard
- Logout functionality
- Responsive design

## Database

Database name:

`department_db`

Table:

`users`

The `users` table stores:

- ID
- Name
- Email
- Password
- Course
- Registration Date
